# server/ — DEPRECATED (легаси Node/Express API)

> **Статус: устаревший. В продакшене не используется.**
> Прод-бэкенд IQMO — это Laravel-приложение в `../laravel/` (Nginx + PHP-FPM
> на VPS, см. `../docs/DEPLOY.md`). Оно реализует те же эндпоинты `/api/*`
> и раздаёт статику из `public/site/`.

Этот Node-сервер — исходная реализация API (auth + синхронизация прогресса
на MySQL). Оставлен как локальный/простой раннер и историческая справка, но
**развивать его не нужно** — все правки делаются в Laravel.

## Чем отличается от Laravel (и почему нельзя гонять в проде)

- **Нет server-side revocation JWT**: не проверяет `users.token_version`,
  поэтому `logout-everywhere` и удаление аккаунта его токены не отзывают.
- **Аналитика только `chem.*`**: не знает про `bio.*`-события.
- **Нет** админки/аналитики, лидерборда, live-activity, воронки квизов,
  публичных профилей, аудит-лога, throttle — всё это есть только в Laravel.

Обе реализации подписывают одну и ту же cookie `iqmo_session` одним
секретом `IQMO_JWT_SECRET` (HS256) — поэтому их нельзя запускать
одновременно на одном домене без риска рассинхрона.

## Запуск локально (если действительно нужен)

Требует MySQL. См. шапку `index.js`.

```
IQMO_JWT_SECRET=<32+ симв> MYSQL_DATABASE=iqmo npm start   # http://localhost:3780
```

Для локальной разработки предпочитайте Laravel-путь (`../laravel`, SQLite,
без Docker) — он ближе к проду.
