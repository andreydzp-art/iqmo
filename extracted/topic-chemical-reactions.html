Если в формулировке задания…

Формулировка / ситуация Сначала проверьте
«Укажите тип реакции» / «относятся к реакции обмена» Два сложных в исходниках? Тогда обмен. Есть простое (металл, H₂…) + сложное — смотрите замещение и ряд активности.
«Восстановите уравнение», «расставьте коэффициенты» Класс каждого вещества → ожидаемые продукты; затем баланс по атомам; для ионного обмена — газ / осадок / вода.
«Какие из перечисленных веществ реагируют друг с другом» Пары «кислота–основание», «металл–соль», «оксид–кислота», растворимость солей; не поддавайтесь на «похожие» формулы без проверки класса.
Схема A → B → C с пропусками Сначала класс вещества на каждом шаге (тема 04), потом типичная реакция для этой пары классов (тема 05).
Типичные ловушки: спутать обмен и замещение; забыть про CO₂ + щёлочь или амфотерный гидроксид; не проверить, идёт ли обмен до конца (нет газа/осадка/воды); в цепочке — «прыгнуть» через несуществующую для ОГЭ стадию. После теории пройдите разминку по слотам 7–12 и при необходимости 8–11 (классы).

5 вопросов по теме
Слоты 7–12 части 1

1. Что считать химической реакцией

Признаки и «закон сохранения»

Новые вещества и часто заметные эффекты

Химическая реакция — процесс, в результате которого из исходных веществ образуются другие: меняются химические связи. На бытовом уровне это может сопровождаться выделением газа, осадка, изменением окраски, теплом или светом — но признак в тетради надёжнее всего: изменилась формула продуктов по сравнению с исходниками.

  • Закон сохранения массы (Ломоносов–Лавуазье): атомы не исчезают, только перестраиваются — в уравнении число атомов каждого элемента слева и справа должно совпасть после расстановки коэффициентов.
  • Заряд в ионных уравнениях тоже сохраняется.
Для теста: если в задании «какой тип реакции» — смотрите на сколько исходников и сколько продуктов, а также обмениваются ли ионы «парами».

2. Типы неорганических реакций (ОГЭ)

Четыре базовых + ОВР отдельно

Реакция соединения (синтез)

Из нескольких веществ — одно более сложное. Пример: 2H₂ + O₂ → 2H₂O; CaO + H₂O → Ca(OH)₂.

Реакция разложения

Из одного вещества — несколько проще. Часто нужен нагрев. Пример: 2H₂O → 2H₂ + O₂ (электролиз воды); CaCO₃ → CaO + CO₂.

Реакция замещения

Простое вещество + сложное → новое простое + новое сложное. Типично металл + соль или кислота (ряд активности металлов!). Пример: Zn + 2HCl → ZnCl₂ + H₂↑.

Реакция обмена

Два сложных вещества обмениваются «партнёрами». Часто в воде: ионы меняются местами. Идёт до конца, если образуется осадок, газ или вода (слабый электролит). Пример: AgNO₃ + NaCl → AgCl↓ + NaNO₃.

Не путать: обмен — всегда два сложных в исходниках; замещение — обязательно есть простое вещество среди реагентов.

3. Условия протекания

Что пишут над стрелкой

Температура, катализатор, электролиз…

Над стрелкой в уравнении отмечают условия: t°, кат. (катализатор), иногда свет или разбавленная/концентрированная кислота. Для электролиза расплавов и растворов пишут электролиз.

Для ионного обмена важна среда и растворимость веществ — по таблице растворимости в билете.

4. Уравнения: коэффициенты и схемы ОГЭ

От «черновика» к верному ответу

Краткий порядок действий

  1. Определите реагенты и продукты (по типу реакции и классу веществ).
  2. Расставьте коэффициенты, проверяя атомы по каждому элементу.
  3. Для ионного обмена можно сначала полное ионное, потом сократить спектаторов.
Пример замещения: Fe + CuSO₄ → FeSO₄ + Cu

5. Шпаргалка: как быстро назвать тип

По структуре уравнения

Исходники (обобщённо) Тип
Много → одно Соединение
Одно → много Разложение
Простое + сложное → … Замещение
Сложное + сложное → два сложных (обмен ионов) Обмен

Алгоритм на минуту

  1. Сколько формул слева? Сколько справа?
  2. Есть ли среди реагентов простое вещество (металл, H₂, O₂…)?
  3. Два сложных и «перекрёстный» обмен ионов → скорее обмен.
  4. Один металл вытесняет другой из соли / реагирует с кислотой → замещение (проверьте ряд активности).
  5. Если меняются степени окисления у нескольких элементов — это уже ОВР (см. блок ниже).

6. Дополнительно

Окислительно-восстановительные реакции (ОВР)

Реакции, в которых меняются степени окисления. Простые вещества почти всегда участвуют в ОВР при переходе в соединения (горение, многие замещения). Для ОГЭ часть заданий сводится к распознаванию окислителя и восстановителя или к уравниванию по электронному балансу — это удобно выучить отдельным блоком курса.

Обратимость и скорость (кратко)

Многие реакции в промышленности идут в заметимую сторону только при выбранных условиях; в школьных задачах ОГЭ обычно дают полные схемы с ясными продуктами. Скорость растёт с температурой и концентрацией, для твёрдых тел — с площадью контакта.
