# IQMO · Страница прохождения теста — инструкция по внедрению

Пакет содержит готовый прототип премиальной страницы прохождения теста IQMO с системой XP, стриков, комбо, XP-банка и анимаций достижения 5/10/15/20.

> Документ ориентирован на интеграцию через Cursor / Claude Code в существующий фронтенд IQMO. Все ассеты ниже — **прототип на ванильном HTML/CSS/JS**, без сборщиков и зависимостей. Внедрять нужно адаптацией под текущий стек (React/Vue/etc.).

## 🎯 Что нужно реализовать в проде

### 1. Маршрут / страница

URL уровня: `/full-test/<subject>/<variant-id>` (например `/full-test-biology/?v=8`).

На странице должны быть:
- Шапка с брендингом, крошками («Биология / Полный вариант ОГЭ»), пилюлями «Помощь» и аватаром пользователя
- Stage-полоса: название варианта, **пилюля «Онлайн · 72 ученика»**, **пилюля-таймер**, **кнопка «Прервать тест»** (все три — в одной форме, скруглённые)
- Левая HUD-колонка: карточка игрока (LVL + XP + Стрик + Комбо), сетка из 21 чипа заданий, **XP Bank**, кнопка «Завершить тест»
- Правая основная зона: прогресс-полоса, **карточка вопроса**, ответы, навигация «Назад / Следующее»

### 3. Структура данных задания

Все 21 задание описываются единым массивом `QUESTIONS` (см. `test-runner-data.js`). Поддерживаемые типы:

| `kind`         | Поле                          | Описание                                |
|----------------|-------------------------------|-----------------------------------------|
| `single`       | `options: string[]`           | Один правильный ответ                   |
| `multi`        | `options: string[]`           | Несколько правильных ответов            |
| `match`        | `prompts[{lbl,text}]`, `pool[{key,text}]` | Соответствие А-1, Б-2…   |
| `sequence`     | `items: string[]`             | Расставить порядок                      |
| `short`        | `placeholder`, `hint`         | Короткий текстовый ответ                |
| `extended`     | `placeholder`                 | Развёрнутый ответ (textarea до 2000 симв.) |
| `image-single` | `imageLabel`                  | Single + картинка (сейчас плейсхолдер)  |
| `table-multi`  | `table{head[],rows[][]}`      | Multi + таблица данных                  |

API задания (минимум):
```ts
type Question = {
  id: number;
  kind: 'single' | 'multi' | 'match' | 'sequence' | 'short' | 'extended' | 'image-single' | 'table-multi';
  title: string;        // короткий заголовок
  body: string;         // HTML тело вопроса
  // зависит от kind
};
```

### 4. Состояние сессии

```ts
type SessionState = {
  cur: number;                          // индекс текущего задания
  ans: Record<number, AnswerValue>;     // ответы по индексу
  postponed: Set<number>;               // отложенные
  visited: Set<number>;                 // открытые
  remaining: number;                    // секунд до конца
  total: number;                        // всего секунд

  // Reward layer
  xp: number;                           // общий XP пользователя
  xpToNext: number;                     // XP до следующего уровня
  combo: number;                        // ответов подряд в этой сессии
  sessionXp: number;                    // XP, заработанный В ЭТОЙ попытке (XP Bank)
  sessionGoal: number;                  // цель сессии (300 XP)
};
```

**Сохранение состояния:** в проде нужен autosave (например, каждые 5–10 сек или при ответе) в backend, чтобы тест переживал перезагрузку страницы. На мок-странице сейчас этого нет.

### 5. Награды (XP / Combo / Streak)

| Действие                              | XP   |
|---------------------------------------|------|
| Первый ответ на single / image-single | +12  |
| Первый выбор в multi / table-multi    | +8   |
| Первое сопоставление в match          | +6   |
| Первая позиция в sequence             | +6   |
| Первый ввод в short                   | +10 (на blur) |
| Первый ввод в extended                | +18 (на blur) |

Изменение ответа повторно XP **не начисляет** (только тост «Ответ изменён»).

При начислении:
1. Над карточкой ответа вылетает «+12 XP» зелёным (22px, monospace, лёгкий halo)
2. 8 золотых частиц брызгают из угла кнопки
3. **Золотая монетка** летит по дуге в XP Bank
4. Цифра в XP Bank тикает count-up и пингует (scale 1.06)
5. Бар сессионной цели заполняется
6. Зелёная плашка «+12 XP» появляется на 1.5 сек возле бейджа банка
7. Кольцо XP игрока пульсирует
8. Глобальный XP игрока инкрементится с tabular-форматированием

**Combo:** растёт за каждый засчитанный ответ. На каждом ×5 (5/10/15/20…) появляется большой золотой флеш `×5 ответов подряд` по центру.

**Streak (дней подряд):** мок-значение 7. В проде — серверный счётчик, сбрасывается при пропуске дня.

### 6. XP Bank

Карточка в HUD над «Завершить тест»:
- Заголовок «⚡ Заработано за сессию»
- Дельта «+12 XP» (зелёная, появляется на 1.5 сек)
- Большой счётчик «0 → 124 XP» с count-up анимацией (cubic ease-out, 700 мс)
- Бар к цели сессии (300 XP)
- Подсказка «Цель сессии — 300 XP. Каждое решённое задание приближает к ней.»

### 7. Фейерверки достижений (5/10/15/20)

Срабатывают при клике на чипы заданий №5, №10, №15, №20.

| Задание | Эффект              | Файл fx-функции |
|---------|---------------------|-----------------|
| 5       | Конфетти            | `fxConfetti()`  |
| 10      | Лучи света          | `fxRays()`      |
| 15      | Звёздная россыпь    | `fxStars()`     |
| 20      | Салют (4 вспышки)   | `fxBursts()`    |

Поверх анимации показывается карточка `★ Рубеж пройден · Задание N из 21 · четверть/половина/три четверти/финиш близко` на 2.4 сек.

Реализация — canvas full-viewport + `requestAnimationFrame`. См. `test-runner-fx.js`. Чтобы запустить в коде:
```js
window.fireMilestone(5);   // 10, 15, 20
```

**Превью** всех 4 анимаций — отдельный файл `Прототипы фейерверка.html` (кнопки 1–4 на клавиатуре).

### 8. Типы задания

В шапке карточки вопроса — две таблетки:
- **Синяя**: `ЗАДАНИЕ N / 21`
- **Серая**: тип задания (`один ответ`, `несколько ответов`, `соответствие`, `последовательность`, `краткий ответ`, `развёрнутый ответ`, `один ответ · рисунок`, `несколько ответов · таблица`)

### 9. Цвета чипов в сетке HUD

| Статус       | Стиль                                                |
|--------------|------------------------------------------------------|
| Текущее      | Синий primary, белый текст, ring + soft shadow      |
| Отвечено     | Зелёный `--green-50` фон, `--green-100` бордер, текст `--green` |
| Отложено     | Золотой `--gold-50` фон, `--gold-100` бордер, текст `--gold` |
| Не открыто   | Белый фон, серый бордер                              |

### 10. Таймер

Пилюля `[Осталось ⏱] HH:MM:SS`. Тикает раз в секунду:
- ≤ 15 мин — переключается в gold (фон, бейдж, цифра)
- ≤ 5 мин — переключается в rose
- = 0 — открывается модалка завершения

### 11. Модалки

- **Прервать тест** — сценарий отказа с предупреждением, что XP и стрик не зачислятся.
- **Завершить тест** — статистика отвечено/отложено/не открыто, кнопка «Завершить и посмотреть» (ведёт на разбор).

### 12. Клавиатурные шорткаты

| Клавиша | Действие                                |
|---------|-----------------------------------------|
| `→`     | Следующее задание                       |
| `←`     | Предыдущее задание                      |
| `1–9`   | Выбор ответа (для single / image-single) |
| `Esc`   | Закрыть модалку                         |

### 13. Доступность

- Все интерактивные элементы — `<button>` с `aria-label`
- Контраст текста ≥ 4.5:1 на светлых поверхностях
- Фокус-кольца на инпутах: `box-shadow: 0 0 0 4px rgba(47,107,255,.18)`
- `prefers-reduced-motion` — **TODO**: в проде отключить ripple и fireworks, оставить fade-переходы

### React/Next.js

   - `<TestRunner>` — корневой

   - `<MilestoneFX>` — canvas overlay, экспозит `useFireMilestone()`
2. Состояние — Zustand / Jotai / Redux. Структуру взять из «Состояние сессии».
3. Данные заданий — fetch из API, типы из раздела 3.
4. Сохранение прогресса — debounced PATCH на backend каждые 5 сек + при ответе.
5. Все цвета вынести в CSS variables (см. токены).
6. Шрифты — через `next/font` (Inter, Space Grotesk, JetBrains Mono).

### Что нужно от backend

```http
GET  /api/test-sessions/<id>          # стартовое состояние + вопросы
PATCH /api/test-sessions/<id>/answer  # body: { questionId, answer }
POST /api/test-sessions/<id>/finish   # завершение, возвращает результат
GET  /api/test-sessions/<id>/live     # SSE/WS: число учеников онлайн
```

XP/combo считаются на клиенте, но **в финале сессии backend должен пересчитать честно** (по верным ответам) и записать в профиль. Клиент только показывает анимацию мотивации.

## 🎨 Дизайн-принципы (важно для качества)

1. **Premium educational, не gaming**. Светлый фон, минимум градиентов, никаких неоновых glow.
2. **3 цвета максимум**: синий primary, золото для наград, зелёный для успеха. Rose только для деструктивных действий.
3. **Большой воздух**. Карточка вопроса — 44px padding, 32px заголовок, 17px тело.
4. **Tactile, не cyber**. Hover поднимает на 1–2px с мягкой тенью, без свечений.
5. **Радости в меру**. XP-эффекты должны быть **видны, но не отвлекать** — длительность 1–2 сек, opacity ≤ 0.9, без аркадной частоты.
6. **Числа — JetBrains Mono с tabular-nums**, чтобы анимации count-up не дёргали layout.
