# 💬 Обсуждение главы — social-блок для IQMO

Лёгкий social-layer для страницы прохождения главы.
Не форум, не чат, не соцсеть — короткие эмоциональные реакции учеников
и ощущение «я не один прохожу эту главу».

## Что внутри

```
discussion-block/
├── discussion-block.html          ← открой в браузере, чтобы посмотреть
├── assets/
│   └── avatars/                   ← 7 PNG-аватарок (badge-стиль)
│       ├── iq-1842.png
│       ├── iq-5521.png
│       ├── iq-1024.png

│       ├── iq-4408.png
│       ├── iq-2210.png
│       └── iq-9973.png
└── README.md                      ← этот файл
```

## Что умеет

- **5 комментариев** видны сразу, **7 скрыто** за кнопкой «Показать ещё 7 ↓»
- **Сортировка**: Популярные / Новые
- **Реакции**: ❤️ 🔥 💀 😭 — без рейтинга, просто toggle. Кнопка «＋» появляется на hover
- **Online-индикатор**: маленькая зелёная точка снизу-справа аватара
- **Presence-pills** сверху: 👀 14 сейчас · 🔥 84% со второго раза · 💀 чаще ошибаются в варианте 6
- **Quiet CTA**: input-style placeholder «Поделитесь впечатлением о главе…» (не доминирует над контентом)
- **Без вложенных веток**: ответы свёрнуты в `💬 N ответов`
- **Адаптивность**: на мобильном комментарии в одну колонку, кнопки full-width

## Установка через Cursor

### Шаг 1. Скопируй папку в проект

Перетащи **всю папку `discussion-block/`** в корень своего проекта IQMO.

### Шаг 2. Открой Cursor и попроси встроить блок

Открой страницу прохождения главы (где у тебя «Твой прогресс / Статистика / Лидерборд / Достижения»)
и в Cursor (⌘+L / Ctrl+L) дай такой промпт:

> Встрой блок «Обсуждение главы» из `discussion-block/discussion-block.html` в текущую страницу.
>
> Правила:
> - размести **ниже** блока «Твой прогресс / Статистика / Лидерборд / Достижения»
> - НЕ выше карты уровней, НЕ внутри тестов
> - перенеси из исходника: `<style>` со всеми правилами `.soc-*`,
>   `<section class="soc-card">…</section>` целиком, и `<script>` в конце
> - оставь пути `assets/avatars/iq-*.png` — папку `assets/avatars/`
>   уже добавил в проект
> - не меняй имена классов и не оборачивай в дополнительные контейнеры —
>   разметка рассчитана на работу без обёрток
> - сохрани шрифт **Manrope** (если в проекте другой шрифт — `font-family`
>   у `.soc-*` элементов наследуется от родителя, можно ничего не менять)

Cursor сам найдёт нужное место и вставит блок. После этого проверь:

- блок появился **ниже** progression-секции
- кнопка «Показать ещё 7 ↓» раскрывает скрытые комментарии
- сортировка переключается, реакции тапаются

### Шаг 3 (опционально). Подключи к данным

Сейчас комментарии — статичная разметка. Чтобы оживить:

```js
// пример: загрузка комментариев с API
fetch(`/api/chapter/${chapterId}/comments?sort=top&limit=5`)
  .then(r => r.json())
  .then(comments => renderComments(comments));
```

Шаблон одного комментария (для рендера через любой фреймворк):

```html
<article class="soc-item">
  <div class="soc-avatar [is-online]">
    <img src="/avatars/iq-{id}.png" alt="" />
  </div>
  <div>
    <div class="soc-meta">
      <span class="soc-name">IQ-{id}</span>
      <span class="soc-dot"></span>
      <span class="soc-time">{time}</span>
    </div>
    <p class="soc-text">{text}</p>
    <div class="soc-actions">
      <button class="soc-react [is-mine]" type="button">
        <span class="em">❤️</span> {count}
      </button>
      <!-- …другие реакции… -->
      <button class="soc-react soc-react-add" type="button">＋</button>
      <button class="soc-replies" type="button">
        <span class="em">💬</span> {replyCount} ответа
      </button>
    </div>
  </div>
</article>
```

Комментарии, скрытые до нажатия «Показать ещё», помечай классом `is-extra` на `<article>`.

## API классов

| Класс                          | Назначение                                              |
| ------------------------------ | ------------------------------------------------------- |
| `.soc-card`                    | корневой контейнер блока                                |
| `.soc-list`                    | список комментариев                                     |
| `.soc-list.is-collapsed`       | скрывает все `.soc-item.is-extra` (по умолчанию)        |
| `.soc-item`                    | одна карточка комментария                               |
| `.soc-item.is-extra`           | скрыто до клика «Показать ещё»                          |
| `.soc-avatar`                  | аватар (44×44)                                          |
| `.soc-avatar.is-online`        | добавляет зелёную точку «в сети»                        |
| `.soc-react`                   | реакция (❤️ 🔥 💀 😭…)                                  |
| `.soc-react.is-mine`           | моя реакция (подсвечена сиреневым)                      |
| `.soc-react-add`               | кнопка «＋», появляется на hover                        |
| `.soc-replies`                 | счётчик ответов (`💬 N ответа`)                         |
| `.soc-more[data-target=".soc-list"]` | кнопка «Показать ещё», раскрывает `.is-extra`     |

## События / JS-логика

В `<script>` уже встроено:

1. **«Показать ещё»** — снимает `.is-collapsed` с `.soc-list` и прячет саму кнопку
2. **Сортировка** — переключает `.is-active` между «Популярные» / «Новые»
   (на бекенд-вызов перевешивай сам)
3. **Реакции** — toggle `.is-mine` + инкремент/декремент счётчика

Если у тебя другой фреймворк (React / Vue) — замени `<script>` на хендлеры
своих компонентов, разметка и стили работают одинаково.

## Зависимости

- **Шрифт**: Manrope (через Google Fonts). Можно заменить — переопредели `font-family`
  в `body` или у `.soc-card`
- **CSS**: только нативный CSS, никаких препроцессоров
- **JS**: ванильный, без библиотек, ~30 строк
